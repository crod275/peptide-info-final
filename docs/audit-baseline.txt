=== PHASE 1 FINDINGS (CSS investigation) ===
Root cause: .pep-loading-state { text-align: center } in styles.css line 924-926
The container divs (#pep-content, #blend-content, #stack-content) have class="pep-loading-state"
in the HTML shells. script.js sets .innerHTML but never removes this class, so all rendered
content inherits text-align: center.

Fix location: script.js — add contentEl.classList.remove('pep-loading-state') before each
innerHTML assignment in renderPeptidePage(), renderBlendPage(), renderStackPage() (3 locations).

is "start" (left-aligned) after fix on all three page types.
